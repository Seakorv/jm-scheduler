# jm-scheduler
Jyväsmetro scheduler app, project to practise some Rust and Typescript.

## Backend

Backend with Rust, can't tell more currently :D

## Frontend

Front will be done with Typescript, nothing more to tell yet :D

There will be three views: Map, Line scheduler and Bar scheduler

## How to run:

Project uses justfile so:
`just test` runs all tests between frontend and backend.
`just test-backend` runs only backend tests.
more commands:
`just fmt` formats
`just lint` lints
`just ready` runs every command in justfile and checks if this would pass CI.
