# jm-scheduler
Jyväsmetro scheduler app, project to practise some Rust and Typescript.

## Backend

Backend with Rust. Two crates in `backend`:

- `jmetro-core` scheduling logic, project model, time math etc.
- `jmetro-api` a thin HTTP layer over the core, using axum and tokio

## Frontend

Front will be done with Typescript, nothing more to tell yet :D

There will be three views: Map, Line scheduler and Bar scheduler

## How to run:

### Prerequisites
- Rust (stable) and [just](https://github.com/casey/just)
- Node (version in `.node-version`) and pnpm
- bacon for backend auto-reload: `cargo install --locked bacon`

### First time
```sh
cd frontend && pnpm install
```

### Development
```sh
just dev
```
It starts both and ctrl + c stops both
- Frontend (Vite) at http://localhost:5173
- backend (axum) at http://127.0.0.1:3000, restarted by bacon on every Rust change

Vite forwards `/api/*` to the backend so the frontend just calls `/api/...`.

### Commands
| Command | What it does |
|---|---|
| `just dev` | backend + frontend with auto-reload |
| `just test` | all tests. `just test-backend` / `just test-frontend`  runs those tests |
| `just fmt` / `just lint` | format / lint + typecheck |
| `just types` | regenerate the TS types from the Rust types |
| `just ready` | format, lint, and tests. |
| `just check` | What CI runs |

### Backend config
Env variables, optional.

| Variable | Default |
|---|---|
| `JMETRO_HOST` | `127.0.0.1` |
| `JMETRO_PORT` | `3000` |
| `JMETRO_LOG_LEVEL` | `info,tower_http=debug` |
| `JMETRO_ALLOWED_ORIGIN` | `http://localhost:5173` |
